# ICS 499 – Software Engineering & Capstone Project Ideas

The following are intentionally **high-level project descriptions**. Your team is expected to understand the problem, identify the stakeholders and goals, elaborate the requirements, determine the scope, and propose an appropriate technical solution.

## 1. OMDB – Online Movie Database- Version 2.0

- Build an online movie database.
- Maintain information about:
  - Movies
  - People (actors, directors, and others)
  - Songs
- Model and manage the connections among movies, people, and songs.
- Provide useful ways for users to search, browse, and navigate the information.

## 2. D3S3 – Version 2.0

- Enhance the existing D3S3 application.
- The application is a healthcare portal for a nonprofit hospital focused on women's preventive care.
- Review the existing system and identify opportunities for improvement.
- Propose and implement meaningful enhancements for Version 2.0.

## 3. Word Wheels

- Build a system for generating Word Wheel puzzles.
- Accept a word or phrase containing 7, 8, or 9 characters.
- Generate puzzles based on the supplied word or phrase.
- Generate and maintain the corresponding answers.
- Design the application so that it can support languages other than English.

## 4. Match-Makers

- Build a profile-matching application.
- Ask users a set of questions.
- Allow the questions to be dynamic/configurable.
- Build and save a profile based on each user's responses.
- Compare a new user's responses against existing profiles.
- Identify one or more matching profiles.
- Provide a confidence/match score for each recommended match.

## 5. RAG and RAG Evals – Version 2.0

- Build an enhanced RAG system for prospective Metro State University students.
- Support multiple users.
- Support multimodal information and media.
- Allow users to ask questions using natural language.
- Retrieve relevant information and generate useful responses from the available Metro State knowledge sources.
- Explore appropriate approaches for multimodal RAG.

## 6. Code Dependency Graph

- Build a tool that creates a dependency graph for a software codebase.
- Accept source code from:
  - A GitHub repository
  - A GitLab repository
  - A local folder
  - An uploaded ZIP file
- Analyze relationships and dependencies within the code.
- Represent the dependency information using Neo4j or another appropriate graph technology.
- Provide useful ways to visualize and navigate the dependency graph.
- Allow users to explore relationships within the codebase.

## 7. Play and Learn – Python 101, Version 2.0

- Build an interactive course and quiz platform.
- Use games or interactive activities to help students learn concepts.
- Provide quizzes for assessment.
- Track individual student progress.
- Provide useful feedback based on student performance.
- Demonstrate the system using **Python 101** as the reference course.

## 8. Play and Learn – Java 101, Version 2.0

- Build an interactive course and quiz platform.
- Use games or interactive activities to help students learn concepts.
- Provide quizzes for assessment.
- Track individual student progress.
- Provide useful feedback based on student performance.
- Demonstrate the system using **Java 101** as the reference course.

## 9. YouTube Channel Analyzer

- Build a website for analyzing a YouTube channel.
- Collect and analyze information about the channel's videos.
- Produce useful reports and statistics, such as:
  - Number of videos
  - Video lengths
  - Likes
  - Comments
  - Video-posting trends
  - Other meaningful metrics
- Convert video/audio content to text when appropriate.
- Build a RAG-based question-answering system over the channel's content.
- Allow users to ask questions about information contained across the channel's videos.

## 10. Project ABCD – Version 3.0

- Enhance the existing Project ABCD application.
- Develop an AI-assisted tagging/classification capability.
- Add a RAG-based chatbot.
- Review the existing application and identify additional opportunities for improvement.
- Propose and implement meaningful Version 3.0 enhancements.

## 11. REBUS

- Build an AI-assisted REBUS puzzle system.
- Use AI to assist with image generation.
- Generate REBUS puzzles.
- Generate and maintain answers for the puzzles.
- Allow users to play/solve the generated puzzles.
- Explore how AI can help create interesting and meaningful puzzles.

## 12. Voice Cloner

- Build an application that accepts:
  - A sample voice/audio file (such as MP3)
  - Input text
- Convert the supplied text to speech using a standard AI-generated voice.
- Convert the same text to speech using the supplied sample voice.
- Allow users to compare the generated outputs.
- Investigate appropriate AI models/services and responsible-use considerations for voice cloning.

## 13. Data Anonymization

- Extend the existing Data Anonymization assignment into a full-fledged application/toolset.
- Support multiple data-anonymization use cases.
- Support one-way anonymization.
- Support two-way/reversible anonymization where appropriate.
- Allow users to work with different types of datasets.
- Explore additional techniques for protecting sensitive information while preserving useful data.

## 14. RAG Works

- Build a framework for understanding and implementing different types of Retrieval-Augmented Generation (RAG).
- Identify and organize different RAG architectures and approaches.
- Provide a way to describe/articulate the characteristics of each type of RAG.
- Develop one or more reference implementations.
- Demonstrate how the framework can be used to understand, compare, and build RAG applications.
